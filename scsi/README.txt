SCSI images with ZuluSCSI names (they need the EPS-16 Plus SCSI option,
which the emulator always has installed):
  HD0.img   hard disk on ID 0 (writable)
  CD5.iso   CD-ROM on ID 5 (read-only)
  RE1.img / MO2.img  removable / magneto-optical
A new, already formatted disk can be created in View > Options > SCSI DRIVES
(50 MB to 2 GB). An empty file (e.g. 100 MB) can also be formatted on the EPS
itself: Command > System-MIDI > FORMAT SCSI DRIVE.
